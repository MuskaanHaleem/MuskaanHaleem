## Featured Project

### 🧠 Karachi Retail Intelligence — Conversational Analytics Agent

An AI analytics platform that lets users query a live retail database in plain English. Natural-language questions are turned into validated SQL, executed read-only against PostgreSQL, and returned as business insights — no manual query-writing required.

**[Live Demo](https://karachi-retail-intelligence.streamlit.app/) · [Repository](https://github.com/MuskaanHaleem/karachi-retail-intelligence)**

```
User Question → LLM Reasoning Agent → SQL Generation → Query Validation → PostgreSQL → Business Insight
```

| Layer | Technology |
|---|---|
| AI Workflow | LangGraph + Groq LLM (Llama 3.3 70B) |
| Backend | FastAPI |
| Database | PostgreSQL (Neon) |
| Frontend | Streamlit + Plotly |
| Security | Read-only DB access, validated query execution |

Notable engineering detail: diagnosed and resolved a PostgreSQL query-planner issue (`Memoize` caching non-deterministic `random()` results in low-cardinality subqueries) by disabling memoization for the affected query path — the kind of debugging that only shows up once real data hits a real database.
